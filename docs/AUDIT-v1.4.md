  - 底部导航切换有焦点态（4 项固定）；

  - 账本 25 轮分页 20+5；
  - 分享海报平均时薪两行显示（例如 130.0 万两/时 / ≈ 8.8 元/时）；

  - 手机号相关代码已清除，小程序包内无 getPhone / getPhoneNumber 调用；
  - 云函数 `wxacode` 生成小程序码成功（base64 约 71KB），分享海报已带真实码；

  - 腾讯文档报表文档归属开发者账号（A 版），用户级 OAuth 待后续；
