## 3. 微信开发者工具：上传新版本

1. 打开项目 `F:\zz12hui\mhxy-getcash-toolsbox`，确认当前为 `master` 分支
2. 点击「编译」，在模拟器/真机预览走一遍首页 → 宠环/人环 → 收益账本 → 分享海报
3. 右键 `cloudfunctions/docsReport`、`wxacode`、`init`（如有改动）→「上传并部署：云端安装依赖」
4. 点右上角「上传」
   - 版本号：`1.4.0`
   - 项目备注：`v1.4.0 单屏首页 / 金价计算器 / 收益账本 / 分享海报 / 腾讯文档报表`
5. 上传完成后，在微信公众平台「管理 → 版本管理」里会看到开发版本

## 4. 提交审核

1. 微信公众平台（mp.weixin.qq.com）→ 管理 → 版本管理 → 开发版本 →「提交审核」
2. 填写：
   - 功能页面：`pages/index/index`（可补充 `pages/pet/pet`、`pages/chain/chain`、`pages/ledger/ledger`）
   - 测试账号：核心功能无需登录；如需测腾讯文档，使用微信登录
   - 补充说明：本地记账工具，无交易/提现；腾讯文档报表需云环境配置；分享海报含相册保存
3. 隐私与合规：
   - 「设置 → 服务内容声明 → 用户隐私保护指引」同步勾选：头像/昵称、相册（保存海报）、剪贴板、反馈、云备份、腾讯文档报表
   - 确认小程序类目与实际功能一致
4. 提交后等待审核；审核期间不要修改线上版本

## 5. 发布上架

1. 审核通过后，版本管理 → 审核版本 →「发布」
2. 选择全量发布（或按需分阶段）
3. 发布后在微信「搜一搜」/小程序入口验证：
   - 首页一屏、4 个 Tab
   - 宠环/人环各记一环
   - 账本平均时薪两行 / 分享海报 / 腾讯文档生成与更新
4. 若发现严重问题，可在版本管理里回退到上一线上版本

## 6. 审核常见风险

- 名称/文案含「搞钱」「收益」等，需在审核说明中强调是游戏内记录工具，不涉及真实交易、提现或代练
- 涉及游戏内容，确认类目与平台规范；不要在页面出现交易/代练引导
- 腾讯文档跳转需要半屏小程序能力；未开通时会降级为普通跳转
- 云函数 Token 有效期（当前到 2026-11-21）；临期前更新 `TENCENT_DOCS_ACCESS_TOKEN` 并重新部署 `docsReport`
