## 4. 云开发部署（登录后）

1. **创建集合**（云开发控制台 → 数据库，6 个）：
   `faq_categories`、`faq_items`、`users`、`user_sync_data`、`feedbacks`、`admins`
   权限：前两个「所有用户可读」；users / user_sync_data / feedbacks「仅创建者可读写」；admins「仅云函数可读写」。
2. **重新部署 4 个云函数**（右键目录 → 上传并部署：云端安装依赖）：
   `init`、`syncUpload`、`syncDownload`、`login`（`submitFeedback` 未改动可不动）。
3. **配置 init 环境变量**（云开发控制台 → 云函数 → init → 配置）：
   - 小程序内初始化：`ADMIN_OPENIDS = <你的 openid>`（先调一次 login，在返回值/日志里看）
   - 控制台云端测试：`INIT_SECRET = <随机长串>`
4. **初始化 FAQ**：
   - 控制台测试：`{"secret":"你的INIT_SECRET","force":true}`
   - 或在已登录的小程序里以管理员身份调用 `init`（`force:false` 即可）
   - 返回 `初始化完成 (100条FAQ)` 即成功。

## 6. 自动化验收（登录 + 服务端口开启后）

项目内置 3 个自动化脚本（基于 `miniprogram-automator`，直接驱动本机开发者工具）：

| 命令 | 覆盖 | 耗时 |
|---|---|---|
| `npm run smoke` | 宠环/跑环新建、连续记录、撤销、常用任务、隐私页、个人中心（7 项） | ~1 分钟 |
| `npm run accept` | 上述 + 环号跳转、批量填充、价格设 0 生效、物品名 chips、隐私协议 Tab、账号页/反馈页入口、使用引导点空白关闭、账本页/筛选/人民币切换、首页大栏目/金价计算器/物品参考价/我的页入口（25 项） | ~2 分钟 |
| `npm run accept:fresh` | 先清 storage 缓存再跑上面 25 项（推荐首次/数据较乱时） | ~2 分钟 |
| `npm run accept:cloud` | 微信登录、FAQ 云端读取、云备份写入+读回、init 鉴权、反馈提交（8 项） | ~2 分钟 |

### 本机已执行结果（2026-10-23，开发者工具 2.02.2608080）

- `npm run smoke` → **7/7 通过**
- `npm run accept` → **25/25 通过**
- `npm run accept:cloud` → **8/8 通过**

云函数已通过 CLI 部署到环境 `<YOUR_CLOUD_ENV>`：`init`、`login`、`syncUpload`、`syncDownload`。

### 自动化已知限制

- `page.callMethod` 在该工具版本不可用，脚本统一改用「真实点击 + `page.setData`」；
- `scroll-view` 内的卡片偶发坐标点击不生效，脚本对这类元素改用 `trigger('tap')`；
- `wx.showModal` 原生弹窗无法被自动化，**结算确认、云端恢复确认需要人工点一次**；
- 自动化会产生测试数据：本地测试跑环记录、云端 1 条备份、1 条反馈。可在 IDE「清缓存 → 清除数据缓存」重置本地；云端测试数据可在云控制台按 openid 清理。

> 若报「连接自动化失败」：确认已扫码登录、设置 → 安全设置 → 服务端口已开启、项目能正常编译；脚本会自动调用 `cli auto` 启动自动化端口。

## 9. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 编译报 `cloud init` 失败 | 未登录或云环境 ID 不对；确认 `app.js` 的 env 与你的云环境一致 |
| 知识库空白/加载失败 | 集合未创建、权限不对，或未执行 init |
| 登录失败 / 云函数调用失败 | 云函数未部署，或 AppID/环境不匹配 |
| 备份失败 | `user_sync_data` 集合不存在或权限不对 |
| `npm run smoke` 启动失败 | 未扫码登录 / 服务端口未开启 / 项目编译失败 |
| 图标/样式异常 | 基础库切换为 2.24.0 及以上，勾选「不校验合法域名」不需要（本项目无外部请求） |
